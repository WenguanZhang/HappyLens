## 📢 Announcement

We introduce **HappyLens** 🥳, an open-source project dedicated to exploring new possibilities in lens design through differentiable ray tracing. 

> We hope optical designers can stay happy while designing lenses, even though we know it is impossible. 🥲

So far, we have completed the following works based on **HappyLens** 🥳:

### 🔍 [Zoom Lens Structure Search with Differentiable Ray Tracing](https://www.sciencedirect.com/science/article/pii/S2590123026034262)

📖 *Results in Engineering, 2026*

We propose **ZED**, an automated framework for searching practical zoom-lens structures from scratch without relying on patent libraries or training datasets.

### 🔍 [Lens Component Deletion based on Differentiable Ray Tracing](https://openaccess.thecvf.com/content/CVPR2026/html/Zhang_Lens_Component_Deletion_based_on_Differentiable_Ray_Tracing_CVPR_2026_paper.html)

📖 *IEEE/CVF Conference on Computer Vision and Pattern Recognition (CVPR), 2026*

We explore a new paradigm for lens simplification by automatically identifying and deleting suitable lens components while maintaining imaging quality, opening up new possibilities for more compact and cost-effective optical systems.

### 🔍 [Differentiable Design and Digital Imaging Compensation for Micro Catadioptric Systems](https://opg.optica.org/oe/abstract.cfm?doi=10.1364/OE.607045)

📖 *Optics Express, 2026*

We extend differentiable lens design to micro catadioptric systems by combining a nested tolerance model with digital imaging compensation, improving system robustness to manufacturing and assembly errors.

### 🔍 [End-to-End Automatic Lens Design with a Differentiable Diffraction Model](https://opg.optica.org/oe/fulltext.cfm?uri=oe-32-25-44328)

📖 *Optics Express, 2024*

We present an end-to-end framework for automatic fixed-focus lens design. The framework jointly optimizes the lens system and image-processing network while accounting for diffraction effects.
